## 一、先开 SuperGrok：半价进门

2026-08-17，我自己把 100 刀 Heavy 这条链跑了一遍。先买会员，再补差价。

第一步，用这条定向优惠开通 SuperGrok：

[https://grok.com/supergrok/targeted-offer/email-supergrok-50-off-2mo](https://grok.com/supergrok/targeted-offer/email-supergrok-50-off-2mo)

结账页当时是这样：

| 项目 | 金额 |
|---|---|
| SuperGrok 月付 | ¥210 |
| SuperGrok Discount（2 个月 50%） | −¥105 |
| **今日应付** | **¥105.00/月** |
| 汇率 | 1 USD = 7.0000 CNY |

看这张表，只抓两件事。第一，进门只要 105 块，折合 15 刀。第二，优惠只有两个月——别停在这儿，这只是跳板。

## 二、补差价上 Heavy：67 折锁三个月

SuperGrok 开通后，立刻打开第二条：

[https://grok.com/supergrok/targeted-offer/email-supergrok-67-off-3mo](https://grok.com/supergrok/targeted-offer/email-supergrok-67-off-3mo)

页面写的是 SuperGrok Heavy **$99 USD/月**，67% 折扣 3 个月，之后回到 $300/月。

点确认更新，当天扣的是补差价：

| 项目 | 金额 / 说明 |
|---|---|
| SuperGrok Heavy Discount | 3 个月优惠 67% |
| 从 2026-09-16 起月费 | 约 ¥693 ≈ US$99 |
| 今天应付 | ¥589 ≈ US$84 |
| 同日第二张发票 | $15.00 Paid（首月补差价） |
| 第 2、3 个月各 | $99 |
| 折扣到期后 | $300/月 |
| 账单 | SuperGrok Heavy Active Offer |
| 将于 | 2026-09-17 续费 |
| 67% 折扣截至 | 2026-11-17 |

看这张表，只抓两件事。第一，两张 Invoice 同一天：$84.00 Paid + $15.00 Paid，首月实付 99 刀。第二，后两个月按 99 走，折扣写到 11 月 17 日，到期回 $300。

## 三、领齐附赠：Cursor Ultra、X Premium+、Grok Bot

Heavy 不只是把聊天变贵。它把三个入口打进同一张会员里，不另开一张卡。

| 附赠 | 怎么领 | 额外费用 |
|---|---|---|
| Cursor Ultra | [cursor.com/promos/grok-heavy-ultra](https://cursor.com/promos/grok-heavy-ultra) | 无。官方写 $0，Heavy 续上就继续免 |
| X Premium+ | Grok 设置 → 账户 → X 账户 → 连接 | 无。Heavy 含 X Premium+，绑定后同步 |
| Grok Bot | [x.ai/bot](https://x.ai/bot) | 无 |

Cursor 帮助页写得很死：要有**生效中的 SuperGrok Heavy**；一对一绑到**个人** Cursor 账号；团队账号不在这个优惠里；已经在 Ultra 上的，不会再叠一份。链接本身不是 Cursor 付款。

X 会员：Grok 左下角打开设置，账户页里点 X 账户的「连接」。Heavy 自带 X Premium+，绑自己的号才能同步过来。

Grok Bot 打开 [https://x.ai/bot](https://x.ai/bot) 领。

三步，五分钟。入口焊在一块了。

## 四、年付 891：另一笔账

67 折三个月之后是 $300/月。不想按原价续，账单页还有一条年付。

路径：Grok 左下角 **设置 → 账单 → 切换计划** → 页面底部勾上「选择年付方案省更多」→ 点 SuperGrok Heavy 那栏 **$3,000 USD/年** 的「切换到每年」。

付款页当时已经是 891，我截了确认页，**没有点确认**：

| 项目 | 金额 |
|---|---|
| SuperGrok Heavy 年付标价 | ¥21,000 ≈ US$3,000/年 |
| **今日应付** | **¥6,248.15 ⇋ US$891.07** |
| 文案 | 从 2027-08-16 起按年收取 |

$891 ÷ 12 ≈ $74/月，比 67 折的 $99 还低。但你得一次掏 891 刀。

确定这一年 Heavy 算力吃得满，年付是锁价。三个月后可能降档、换入口，月付更活。付款页在，决定留给你。

## 五、这条链值多少

回到凌晨那个问题。

| 权益 | 单独买 | 这次领到的 |
|---|---|---|
| SuperGrok Heavy 算力 | $300/月标价 | 三个月 67 折，$99/月 |
| Cursor Ultra | 另购（个人档） | Heavy 有效期内 $0 |
| X Premium+ | 另购 | Heavy 内含，绑定后同步 |
| Grok Bot | 走 x.ai/bot | 随 Heavy / Ultra 领取 |
| 额度重置 | — | 开通附赠一次，9 月 13 日前兑 |

看这张表，只抓两件事。第一，300 刀原价买的是速度。第二，99 刀优惠买的是上面整张表一次领齐——不是聊天月费，是入口费。

我在意的不是省了几十刀。一个下午把入口焊好，接下来三个月不用再比价、不用到处找激活链接。省的是注意力。

云电脑里那个任务后来跑完了。40 分钟，结果还行。300 刀值不值，看你拿它干什么。99 刀值不值，看你手里攥了几把钥匙。
