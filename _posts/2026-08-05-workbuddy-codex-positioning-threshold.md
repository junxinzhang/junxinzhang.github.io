最近后台被问得最多的一个问题：

**WorkBuddy 和 Codex，到底谁更强？**

我的答案可能让两边粉丝都不爽：**这个问题本身就问错了。**

一上来就问谁更强，就像问卡车和跑车谁更强。你先告诉我：你是要拉货，还是要下赛道？

> **工具没有输赢，只有定位。而在国内，真正的分水岭不是能力，是上手门槛。**

## 一、先给结论：我两个都用，分工很清楚

不搞悬念，直接上我自己的真实用法：

**复杂工程，我选 Codex；日常办公、做 PPT、远程调度又不想折腾，WorkBuddy 更顺手。**

| 维度 | Codex | WorkBuddy |
|------|-------|-----------|
| 出身 | 为开发而生 | 为办公而生 |
| 典型任务 | 复杂工程、多仓库协作、深度重构 | Excel、报表分析、PPT、远程调度 |
| 依赖环境 | 终端、runtime、网络、账号 | 开箱即用 |
| 目标用户 | 码农、把 AI 用得更深的人 | 普通白领、国内办公场景 |
| 国内上手 | 门槛极高 | 门槛极低 |

我八月一号写过 [用 Codex 两小时交三端](/codex-stitch-two-hours-three-ends-recall)——那种活，WorkBuddy 碰都碰不了。但反过来，让一个从没开过终端的行政同事装 Codex？别闹了。

选择逻辑就一句话：

**普通白领用户选 WorkBuddy；码农或者想把 AI 用得更深的，选 Codex。**

定位不同，确实没必要硬分输赢。

## 二、门槛才是国内最现实的分水岭

很多测评喜欢比模型能力、比 benchmark。但在国内的真实场景里，这些都排在第二位。

**排第一位的是：这个人能不能把工具跑起来。**

教 Codex，光网络和账号问题就能卡住 99% 的人。安装要终端，注册要海外手机号或邮箱，支付要外币卡，网络还要自己想办法——每一步都是一道劝退墙。国内非技术用户，光安装注册这一关就能被劝退大半。

而 WorkBuddy 呢？打开就能用。

所以我现在的建议非常简单粗暴：

**国内想要教别人用 AI，无脑 WorkBuddy 就完事了。合法、合规、合理。**

这不是说 Codex 不好——是说在「让一个普通人真正用上 AI」这件事上，**可得性比能力更重要**。一个跑不起来的顶级工具，价值等于零。

## 三、从推文里读到的几条信号

这周刷到几条关于 WorkBuddy 和腾讯企业 AI 布局的公开讨论，信息密度不低。我没去现场聊，也没急着掏钱买企业席位——先把能核对的说法摊开，再叠自己的判断。

### 1）有人把它放到「QQ、微信之后」的位置

圈子里传得最狠的一句话是：**WorkBuddy 是腾讯历史上第三个战略级产品，前两个是 QQ 和微信，战略上抢的是企业 AI 的入口。**

这话要打折听——「战略级」最终由市场验证，不是由口号验证。但方向很清楚：如果腾讯真按这个级别押，它就不是一个「试试水」的工具型产品，而是下一个十年的入口卡位。

入口级产品的打法，通常不是先把硬核开发者伺候到爽，而是先把**组织采购、合规、协同入口**占住。这也解释了为什么它更像办公产品，而不是 Codex 那条开发原生路线。

### 2）企业 AI 转型，每个人都有巨大的机会

把公开讨论里反复出现的路径压一下，企业觉醒基本是三段：

1. **超级个体先觉醒**：让 AI 干活，人回归决策，效能直接翻 10 倍
2. **能力外溢到团队**：把方法分享给团队，整体提效 30%~50%
3. **经验沉淀到组织**：整个组织再提效 30%~50%，这已经是胜利

但这里有个大坑：**很多老板看到员工效能翻 10 倍，第一反应是裁人——这是最傻的，等于把最宝贵的人才赶走。**

反过来说，主动觉醒、先成为超级个体，才是每个人破局的关键。工具选 WorkBuddy 还是 Codex 是第二步；**你自己有没有先把 AI 用进真实工作**，才是第一步。

### 3）一个新岗位：AIBP

过去有 HRBP，现在会有 **AIBP（AI 伙伴）**。

之前大家谈 FDE（驻场工程师），本质还是外包逻辑——派到企业做完转型，人一走，能力也带走了。

而 AIBP 是**组织自己的人**：老板把他派到一个部门，帮整个部门 Agent 化；效能提升了，再去下一个部门。这种长在组织内部的 AI 推手，现在极度稀缺。我的判断是：**AIBP 比 FDE 更好。**

公开讨论里还有一条很土的供需错位：大厂和企业侧接触了大量需求，但**能用 Agent 真正解决具体场景的人供给不上**。这意味着：

- 会用 Agent 的人，比只会讲「赋能」的人值钱
- 生态位缺口不在口号，在落地
- 如果后续出现「走进腾讯」、架构师答疑、带业务骨干现场解题这类活动，本质也是在补这条供给链

对我们自己的社群逻辑也一样：一边帮人把 Agent 用得更深，一边把用得好的人对接到真实企业场景——**用得深的人挣到钱，企业拿到结果**，才算闭环。

## 四、说句不客气的：WorkBuddy 满足的是付钱的老板

信号看完，该说尖锐的了。对照它的产品形态和 Codex 那条开发原生路线，我必须说一句不太客气的话：

**WorkBuddy 是一款满足付钱的管理者，但还没有足够尊重底层使用者的软件。**

它精准命中了「付钱但不使用」的老板们对 AI 软件的全部预期：界面像个正经企业软件、数据在国内、能出报表、能对接组织架构、采购流程走得通。老板看一眼演示就愿意签单。

但对每天真正干活的人来说，它和 Codex 的差距是**内核和底层**的差距：

| | WorkBuddy | Codex |
|---|-----------|-------|
| 能力边界 | 办公场景：Excel、报表分析、PPT | 完整工程能力：runtime、代码、长任务 |
| 干活方式 | 帮你把表做出来 | 把整段工作委托出去 |
| 天花板 | 办公助手 | AI Native 的生产方式 |

我昨天在 [你的公司电脑，可能连 Agent 的门都进不了](/agent-runtime-beyond-laptop-infrastructure) 里写过：没有 runtime 的 Agent 就是个聊天框。WorkBuddy 目前的形态，离 AI Native 的真实价值——让 AI 真正接管整段工作、人回归决策——还有一段不小的距离。

**它满足了老板的预期，但还没满足 AI Native 的价值。** 这一刀我必须切在这里，不然前面的夸就成了软文。

## 五、但窗口期是真的：半年到一年

批评归批评，我的整体判断反而是乐观的：**WorkBuddy 大有可为。**

原因有三：

**第一，它是更适合中国宝宝体质的 Agent 工具。** 合法合规、开箱即用、数据不出境——这三条在国内企业采购里是一票否决项，它全过。

**第二，生态已经打通了国内外的一部分。** 后续就是生态位的抢占：谁能打通得多，谁就先占住用户心智。企业 AI 入口这个位置，先到先得。

**第三，窗口期还在。** 昨天我写了 Harness 层即将过时——本地笔记本级别的 Agent 工具很快会被下一代运行方式取代。但那是前沿玩家的时间表。**对国内市场，至少还有半年到一年的窗口期。** 这段时间里，谁能把「门槛低 + 合规 + 生态」三件事做扎实，谁就能在下一轮范式切换前攒下足够的用户资产。

## 写在最后

压成五句：

1. **别问谁更强，先问拿它干什么**——复杂工程选 Codex，日常办公选 WorkBuddy，定位不同没有输赢
2. **国内真正的分水岭是上手门槛**——光网络和账号，就能把 99% 的非技术用户挡在 Codex 门外
3. **公开讨论里它被放到 QQ、微信之后的战略级位置**——抢的是企业 AI 的入口，方向比口号更重要
4. **尖锐的一刀**——它满足了付钱的老板，但离 AI Native 的真实价值还有距离，差距在内核和底层
5. **窗口期半年到一年**——门槛低 + 合规 + 生态三件事做扎实，就能在范式切换前占住心智

土话一句：

**教普通人用 AI，无脑 WorkBuddy；自己想变强，老老实实上 Codex。**
