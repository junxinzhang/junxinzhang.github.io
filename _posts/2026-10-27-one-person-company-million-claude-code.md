### 我为什么不卖课

不少朋友开始做一人公司，第一件事是开班。写招生文案，拉学员群，开直播，半夜改课件。

如果你不是特别缺钱，别走这条弯路。

上一小时课，收一小时的钱。停一个月，收入就停一个月。你得一直招新学员，在群里回答重复的问题，照顾每个人的情绪。名头换成了自由职业，干的还是拿时间换钱的活，和你上班没有本质区别。

![避开授课陷阱与软件资产](/assets/images/illust-20261027-course-trap-vs-product-cashflow.webp)

我把时间押在产品上，押在能立马收钱的产品上。

代码写好，部署上线，接上 Stripe。用户下单，系统交付，我睡着了，服务器还在收钱。

![Stripe 新建订阅收款](/assets/images/illust-20261027-zaokit-stripe-subscription-creation-19.webp)

拿 Zaokit 举例。

Zaokit AI PPT 能私有化部署。现在它装在某快消巨头的内网里，一个部门接着一个部门往下铺。每进一个部门就是一单真实成交，用的人提意见，意见当天到我手上，我改完再发版。产品就是这样一单一单磨出来的。坐在课堂里的学员，给不了你这种反馈。

有些企业装不了本地版，我给它们 Zaokit Cowork。员工打开浏览器，就能用上最新的 Harness 和 AI 工具。

企业要做内部培训，Zaokit AI Edu 当天就能把材料做成图文和带配音的片子，拿去路演。

Zaokit SSO 接进客户所有的业务系统，替他们管好登录这件小事。

价格都写在各产品的内购价格表里，感兴趣可以去看。

半年前写的代码，今天还在收钱。老用户到期，订阅自己续上：

![Stripe 订阅续费更新](/assets/images/illust-20261027-zaokit-stripe-subscription-update-19.webp)

撕掉课件，去写能收钱的软件。

### 围着 Claude Code 和 Codex 做产品，越快越好

以前一个人做软件，卡在工程量上。前端、后端、数据库、登录、支付对账，一套下来三个程序员要干几个月。

现在我打开终端，Claude Code 和 Codex 一起开。我写清楚业务边界、数据结构和验收标准，Claude Code 理文件、搭目录、改旧代码，Codex 写算法、修编译错误、补测试。我的时间花在判断上：这个功能该不该做，做到哪一步算完。

“围着”这两个字，我想多说一句。

Zaokit ClaudeOps 就是围着 Claude 长出来的产品。我自己重度写代码，前后被封了 17 个账号，网络掉线、海外卡拒付、环境配置，每样都踩过。踩完，我把这套环境打包成服务，10 月 16 日由澳洲公司对全球[上线]({{ site.baseurl }}/zaokit-claude-ops-global-launch)。

工具每升级一次，用它的人多一批，围着它的麻烦也多一批。麻烦里有生意。

### 3000 个铁粉就够了

产品做出来，下一个问题是谁来买。

大公司买广告、养销售。一人公司那点钱，投信息流烧不了几天。

我的办法是写文章和做视频，并且把它排在所有事情前面。

踩过的坑，付过的账单，被封号的经过，我都写出来。不讲大道理，讲服务器怎么挂的，账是怎么算的。

我现在的关注是 1400，离 3000 还差一大截。而且铁不铁还不清楚～可我 C 端的客户，全是读了文章找过来的，没有一个是买广告买来的。

所以我信 3000 这个数。3000 个知道你水平、认你审美的人，新东西上线他们先买，买完给你挑毛病，碰到合适的生意会想起你。

一个人关起门做事，能撞上的机会就那么几个。你写出去的每一篇，都在替你见人。

影响力排在所有事情的最前面。它决定你的幸运面有多大。
