## 一、换皮是什么，为什么这周才死

换皮这门生意，过去两年很好做。

你接一家模型的 API，套一个聊天框、一个侧边栏、一个「AI 助手」。改个名字，上个订阅页，就能收钱。用户要的其实是后面那家模型的能力，但他们懒得自己去申请密钥、配环境、调参数——你赚的，就是这份懒。

这生意能活，有两个前提：

1. **模型从来不到用户面前**——它住在 API 后面，必须经过你的产品
2. **「够用的智能」还贵**——用户付你溢价，觉得比自己去源头划算

这两个前提，这周同时塌了。

周三，Grok 4.6 发布，首日上线 Cursor 和 Grok Build，还送一周双倍额度。周四，Gemini 3.7 Flash 价格砍半，五项干活指标跳涨。模型不再藏在 API 后面等人来包，它直接住进了入口；便宜的智能也不再只能聊天，它开始能干重活。

**换皮靠的是用户懒得去源头。源头把店开到他桌前了，你还卖什么？**

## 二、Grok 4.6 首日进 Cursor：模型绕过了中间商

Grok 4.6 的发布方式，比它的分数更狠。

SpaceXAI 官方写得很清楚：今天发布，今天就在 Cursor 和 Grok Build 里可用。API、OpenRouter、Vercel、Cloudflare 随后跟上。首周双倍额度，就是怕你不立刻打开来用。

定价也不含糊：每百万 token 输入 2 美元、输出 6 美元。在 Artificial Analysis 综合指数上追平 GPT-5.6 Sol，CursorBench 69.9%，长程知识工作 GDPval 还略领先。分数可以争，**分发不能争——发布当天，模型已经坐在几百万开发者每天打开的那个窗口里了。**

以前的顺序是：模型发布 → 你去接 API → 你做成产品 → 用户来用你。现在的顺序是：模型发布 → 用户打开 Cursor → 直接开干。

中间少了你。

| 以前 | 这周开始 |
|------|---------|
| 模型住在 API 后面 | 模型住在 IDE 里 |
| 你是到达用户的必经之路 | 你是窗外多出来的一扇门 |
| 用户为了用模型，才打开你 | 用户打开 Cursor，模型已经在了 |
| 你的订阅卖的是「方便」 | 「方便」被入口免费送掉了 |

更狠的一层：Grok 4.5 已经开始吃 Cursor 的真实使用数据做后训练，4.6 的补充训练跑得更长。入口不只是分发渠道，它是模型的养料。**换皮产品没有这个闭环——你包的是别人的模型，喂肥的也是别人的模型。**

## 三、Flash 半价能干重活：你加的那一层溢价站不住了

同一周，Google 从另一头拆换皮。

Gemini 3.7 Flash 促销价砍到上一代原价的一半：每百万 token 输入 0.75 美元、输出 3.75 美元，促销到今年年底。降价不稀奇。稀奇的是，这回升级冲着干活去——长期软件工程、企业工作流、生产级代码，全都跳涨。以前 Flash 是「快、便宜、够聊天」，3.7 开始是「便宜，但真能接一单活」。

换皮产品的定价，通常长这样：模型成本 + 你的界面 + 你的利润。模型成本一砍半，界面又被入口免费送了，利润那一栏就变成了用户心里的那句问：

**我为什么不自己去源头跑？**

Grok 4.6 是 2 / 6，Flash 是 0.75 / 3.75。两条价格线同时压下来，中间那层「我帮你调好了」值不了几个钱——Cursor 里已经调好了，Gemini 自己的入口里也调好了。

| | 换皮产品卖的 | 这周被谁免费送了 |
|--|-------------|----------------|
| 一个能用的窗口 | 聊天框 / 侧边栏 | Cursor、Grok Build、Gemini 应用 |
| 一次能用的调用 | 包好的 API | 模型官方入口 + 合作伙伴 |
| 一点溢价 | 「我帮你调好了」 | 首周双倍额度、半价工作马 |

[上一篇](/grok46-gemini37-flash-model-knockout)说 Flash 便宜归便宜，真能干重活了。今天把这句话落到换皮头上：**能干重活的便宜智能，不是换皮的红利，是换皮的死刑。** 红利属于直接用模型的人，死刑给的是靠模型价差活着的人。

## 四、还活着的产品，卖的从来不是模型

话说回来，不是所有套了模型的产品都是换皮。

分得清的只有一句话：**用户离开模型，你的产品还在不在。**

还在，你卖的就不是调用，是模型到不了的东西。不在，你就是一层皮。

模型到不了的，通常是这三样：

| 模型到不了的 | 为什么它值钱 |
|-------------|-------------|
| 工作流 | 报关怎么跑、单据怎么核、审批怎么串，不在模型的预训练里 |
| 私有数据 | 客户的账、现场的图、内部的权限，模型既拿不到，也不该拿到 |
| 交付物 | 一份能过审的报告、一张能上会的图、一套能上线的流程，不是一段对话 |

我做 [Zaokit](https://zaokit.ai) 时反复撞上这件事：模型谁便宜好用接谁，价值不能沉淀在调用上。调用是原材料，会过期、会降价、会被入口直接送掉。**能留下的，是把模型、执行环境和企业工作流缝起来的那层胶水。**

胶水不是套壳。套壳是把模型的嘴，换成你的嘴。胶水是让模型去干它自己干不完的那截——登录、取数、过规则、交件、等人确认。

所以这周的信号，对还活着的产品反而是松绑：模型更强、更便宜、更近，原材料更好了。你要做的不是跟入口抢窗口，是把窗口后面那截脏活，做成别人搬不走的交付。

## 五、一张自检表

别急着对号入座「平台」或「小团队」。先问自己四个问题：

1. **用户打开你，是为了你，还是为了后面那家模型？**
2. **模型换一家，你的产品还在吗？**
3. **你有没有模型到不了的数据、流程、权限、交付物？**
4. **你收的钱，比用户自己去 Cursor 或 Gemini 里跑，贵在哪？说得清吗？**

前两题答「为了模型」「不在了」，后两题答「没有」「说不清」——你就是换皮。这周的三记重拳，打的就是你。

过得了，这周是好消息：原材料更便宜，入口更近，你可以把省下来的成本，砸回那层胶水里。

过不了，别改文案，别换皮再卖一次。把产品拆开，看哪一截是模型到不了的；没有这一截，就停。
