Why Private

大模型很强，但不是每份数据都适合上云

合同、源码、客户资料、财务数据……把它们留在自己的机器里，是很多团队的底线。

数据合规顾虑

敏感数据发往第三方 API 存在合规与泄露风险，很多业务场景根本无法使用云端模型。

Token 账单失控

批量处理、Agent 长任务、全员日常问答，按量计费的成本随用量线性上涨。

硬件闲置浪费

办公室的 Mac Studio、带显卡的工作站，大部分时间算力都在空转。

自己部署踩坑多

量化选型、显存/内存规划、上下文长度、多机互联、开机自启，每一步都可能卡几天。

Tuning

不止“能跑”，而是跑得快、跑得稳

每一项调优都有基准测试佐证，交付时给出可复现的数据，而不是一句“已优化”。

模型与量化选型

按内存/显存反推最大可用模型，在 4bit / 8bit / FP8 之间权衡质量与速度，避免爆内存与频繁换页。

上下文与思考模式

按业务设定上下文窗口；默认直接回答以降低延迟，同时保留按请求开启深度思考的能力。

并发与吞吐

测量单请求与双请求吞吐、长提示首字延迟，给出建议的并发上限与机器分工。

开机自启与无人值守

重启后无需登录桌面即可恢复模型、网关与机器互联；关闭自动睡眠，来电自动开机。

访问安全

模型接口仅本机监听，统一由网关鉴权；无密钥请求直接拒绝，凭据独立受控交接，不写入文档。

远程运维与可选公网

通过 ZeroTier / SSH 授权运维；如需外出访问，可选 Cloudflare Tunnel + 邮箱验证的公网入口。

FAQ

常见问题

我的电脑能跑多大的模型？

经验值：24 GB 统一内存的 Mac mini 可流畅运行 9B 级 4bit 模型；64 GB 的 Mac Studio 可运行 27B–32B；128 GB 以上可尝试 70B 级。Windows / Linux 主要看显存：12 GB 显卡适合 7–9B，24 GB 适合 27–32B 量化版。发送型号给我们，免费评估。

部署后数据会经过你们的服务器吗？

不会。模型权重与推理全部在您的设备上运行，基础方案仅限局域网访问。只有当您主动选择开启公网入口时，请求才会经过 Cloudflare 转发；我们的远程运维权限也可以在验收后由您关闭。

需要你们到现场吗？

不需要。全部通过授权的远程连接（屏幕共享 / SSH / ZeroTier）完成。您只需确保设备开机、联网，并在开始时配合授权一次。企业版可另行约定驻场。

效果能和 GPT / Claude 一样吗？

坦诚地说，本地开源模型在复杂推理上与顶级闭源模型仍有差距，但在日常问答、文档处理、代码辅助、批量数据处理等场景已足够实用，且没有调用费用和数据外泄风险。很多客户采用“敏感任务走本地、复杂任务走云端”的混合方式。

可以混用 Mac、Windows 和 Linux 吗？

可以。集群版和企业版支持跨平台混合组网，例如 Mac Studio 跑大模型、Windows 显卡主机跑中模型、Linux 服务器负责高并发，统一由网关按模型名称路由。

交付后模型更新、出问题怎么办？

支持期内免费远程排障。支持期结束后，可订阅“持续运维托管”按月获得模型升级、巡检与性能复测，也可按次付费咨询。交付说明书中包含日常运维与恢复步骤，您的团队也可自行维护。
