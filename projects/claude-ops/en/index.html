Security & Privacy

Two-tier isolation: separate accounts and dedicated machines

Your terminal carries private source code, API keys in environment variables, database settings and business logic. Zaokit ClaudeOps uses two tiers of isolation: on 1x / 5x every user gets a separate macOS account accessed only via Apple Screen Sharing; on 20x you can enable a whole dedicated machine, isolated right down to the hardware.

20x dedicated machine: hardware-level isolation

With dedicated mode enabled, the entire high-spec Mac Studio or Mac mini serves only you. Install any software, change system-level settings, and use any remote desktop tool, including RustDesk and third-party VNC.

1x / 5x separate account isolation

Every user has a separate macOS account with its own files and permissions, so history and project files stay private. Access is via Apple Screen Sharing only, which gives each account its own isolated desktop session that no one else can see.

You control access and encryption

Set your own access passwords and encryption policies. Our team handles connectivity and billing and does not actively access data in your account, except for maintenance, security incidents or troubleshooting you authorise.

Why is Zaokit ClaudeOps priced higher than standard cloud desktops or shared accounts?

Because you are paying for deterministic physical infrastructure and white-glove engineering operations—not low-cost shared VPS instances or pooled logins. Every subscription covers four real infrastructure costs:
• High-Spec Physical Mac Hardware: Real Mac Studio and Mac mini machines (never virtualized cloud VMs), delivering sustained local compute and 24/7 reliability—with full dedicated machine isolation on 20x+;
• 200Mbps–500Mbps+ Symmetrical Native Bandwidth: Local native ISP broadband across 9 countries with generous symmetrical upload/download speeds, keeping Screen Sharing crisp and responsive instead of lagging on 10–30Mbps shared pipes;
• Enterprise BGP Backbone: Self-hosted high-speed relays over a premium HK/APAC enterprise BGP backbone with dual-leg BBR optimization, driving cross-border packet loss to zero;
• Full Official Allowance + 7×16 / 7×24 Concierge Ops: Full official subscription allowances, managed billing, iCloud/Google Drive sync, and 1-on-1 engineering support.

Separate account vs dedicated machine: why is 1x / 5x limited to Apple Screen Sharing?

• Separate account isolation (1x / 5x): several users share one high-spec Mac, but each has their own macOS account, files and permissions, and no one can see anyone else's data. To protect every user's privacy, access is limited to Apple Screen Sharing, which creates an isolated desktop session for each account so your screen and activity stay private.
• Dedicated machine (available on 20x): the entire physical Mac serves only you. Hardware, system and network are fully yours. Install any software, change system-level settings and use any remote desktop tool: Apple Screen Sharing, third-party VNC such as RealVNC / TigerVNC, or our self-hosted high-speed RustDesk channel (complimentary on 20x).
Why no third-party remote tools on shared machines? RustDesk and most third-party VNC tools capture the Mac's main screen session, which on a multi-user machine could let others see or even control your desktop. We only enable them in dedicated mode. It is a deliberate privacy safeguard.

How do I actually use it? Remote Mac or local?

Both work. Use whichever suits you:
1. Remote desktop: on 1x / 5x, sign in to your separate account with macOS Screen Sharing, which is isolated, secure and ready to go. On 20x with dedicated mode enabled, you can also use third-party VNC such as RealVNC / TigerVNC, or our self-hosted high-speed RustDesk channel (complimentary on 20x) for smoother, lower-latency sessions. Either way you get the full macOS desktop and terminal, and long tasks keep running.
2. Seamless local workflow integration: collaborate with the remote development environment directly from your local workflow and dev tools, with no local environment set-up or maintenance overhead. The remote Mac becomes your dedicated compute back end.

How are my code and data kept secure and private?

On 1x / 5x, every user gets a separate macOS account with isolated files, permissions and desktop sessions, accessed only via Apple Screen Sharing so no one else can see your screen. On 20x you can enable a dedicated machine: the entire high-spec Mac Studio or Mac mini serves only you, isolated right down to the hardware. Your session history, source code and environment variables stay in your own account or machine. You set your own access passwords and encryption, and our team does not actively access your data except for maintenance, security incidents or troubleshooting you authorise.
