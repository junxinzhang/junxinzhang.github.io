FAQ

常见问题

Zaokit ClaudeOps 由谁运营？

Zaokit ClaudeOps 由澳大利亚注册公司运营，通过 Stripe 安全结算，每笔付款均自动生成正式收据与账单（Invoice）。服务支持中文与英文（English version）。

1x / 5x / 20x 有什么区别？

三档的核心差异是可用额度：5x 和 20x 分别提供标准版 5 倍和 20 倍的用量，其他服务内容一致，高档位额外享有更高优先级的支持。

我该选哪一档？

日常对话、写作选 1x；每天使用 Claude Code 写代码选 5x；需要多个 Agent 并行或全天候高强度使用选 20x。不确定的话可以先从低档开始，随时升级。

"确定性的稳定环境"具体指什么？

指专属独立工作空间 + 固定的高配置 Mac 物理运行环境 + 专人托管账单续费与日常运维。我们通过规范化的工程运维消除环境中断、配置冲突与续费失败等不确定因素，让您获得可预期的使用体验。

我具体该如何使用？是登录远程 Mac 物理机还是本地调用？

两种使用模式均完美支持，您可以按工作习惯自由选择：
1. 远程桌面 VNC 直连：通过常用的远程桌面客户端（如 macOS 自带屏幕共享、RealVNC、TigerVNC 等）一键直连属于您的专属远程高配置 Mac Studio 或高配置 Mac mini 物理机，拥有完整的原生 macOS 图形界面与终端，开箱即用，长周期任务挂机无忧。
2. 本地开发工作流无缝协同：支持在本地工作流与开发工具中无缝协同远端部署好的开发环境，免去繁琐的本地环境依赖与配置维护，让远程原生 Mac 实例成为您本机的专属算力后端。

代码和项目数据的安全与隐私如何保障？

每位客户均分配独立的专用高配置 Mac Studio 或高配置 Mac mini 物理级运行环境，采用单租户隔离架构，绝不使用多人混部的共享容器。您的会话历史、仓库源码与环境变量仅存储在您专属的实例中，物理上与其他用户零交叉；同时支持您自主设置访问密钥与本地加密策略，运维团队仅负责底层机器连通与账单托管，恪守零数据接触原则。
