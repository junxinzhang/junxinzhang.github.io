FAQ

常见问题

1x / 5x / 20x 有什么区别？

三档的核心差异是可用额度：5x 和 20x 分别提供标准版 5 倍和 20 倍的用量，其他服务内容一致，高档位额外享有更高优先级的支持。

我该选哪一档？

日常对话、写作选 1x；每天使用 Claude Code 写代码选 5x；需要多个 Agent 并行或全天候高强度使用选 20x。不确定的话可以先从低档开始，随时升级。

"确定性的稳定环境"具体指什么？

指独享账号 + 固定的运行环境 + 专人托管续费与运维。我们通过规范化的运营尽可能消除服务中断、扣款失败等不确定因素，让您获得可预期的使用体验。

运行环境的机器部署在哪里？

我们的机器分布在美国、新加坡、澳大利亚、新西兰和加拿大五个国家。开通时为您分配固定机器并长期使用，不随意切换；如对机器所在国家有偏好，咨询时说明即可。

可以中途升级或降级吗？

可以。下一个计费周期即可调整档位，如需当月立即升级，联系我们按差价处理。

出现异常怎么办？

遇到无法使用等异常情况，第一时间联系我们，会优先排查处理，确保您的使用尽快恢复。
